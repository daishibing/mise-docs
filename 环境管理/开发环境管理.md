# 开发环境管理

使用 mise 管理开发环境中的工具和版本

# 安装工具

安装工具的最新版本：

```shell
mise install <tool>
```

安装工具的指定版本：

```shell
mise install <tool>@<version>
```

# 查看工具

查看所有已安装的工具信息：

```shell
mise ls
```

查看指定已安装的工具信息：

```shell
mise ls <tool>
```

查看指定工具的可用版本：

```shell
mise ls-remote <tool>
```

# 卸载工具

卸载指定工具版本：

```shell
mise uninstall <tool>@<version>
```

# 设置全局工具版本

设置全局工具的指定版本：

```shell
mise use -g <tool>@<version>
```

参数说明：

- `-g`：设置为全局版本

# 查看当前工具版本

查看所有当前生效的工具版本：

```shell
mise current
```

查看指定工具当前生效的版本：

```shell
mise current <tool>
```

# 设置当前 Shell 版本

设置当前 Shell 会话使用的工具版本：

```shell
mise shell <tool>@<version>
```
